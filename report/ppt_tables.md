## 表 4：异常和限制

| 问题 | 是否出现 | 证据 | 处理 |
|---|---|---|---|
| 编译问题 | 是 | 初始 colcon 日志 | 隔离 driver 官方 ROS2 布局；补发行版宏 |
| 话题不匹配 | 否 | runtime node/topic info | 使用 driver2 数据副本 |
| 时间同步错误 | 未见时间倒序 | compatibility + trajectory checks | 使用原始 header/offset_time |
| QoS 问题 | 未见丢失导致的失败 | 三次自然结束 | 保留运行期计数 |
| 持续积压 | 否 | drain.json；buffer 1/40 | 尾部无效帧单独审计 |
| RSS 增长 | 是 | RSS slope / R2 | 只报告趋势，不宣称泄漏 |
| 轨迹跳变/分叉 | 是 | 三次 XY 图与等价试验 | 固定调度并增加重复 |
| 缺少 GT | 是 | 数据/协议审计 | ATE/RPE=N/A |
| RViz 不可用 | 是 | Qt xcb 日志，exit -6 | 离线 PCD/轨迹图替代 |
