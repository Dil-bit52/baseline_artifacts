## 1. 本阶段目标

在不改变 FAST-LIO2 状态估计、数据关联和 ikd-Tree 插入/删除规则的前提下，对世界坐标系注册点云做独立体素化，记录体素首次/最近观测、命中、观测帧和时间覆盖，并离线计算“单序列内部持久性代理分数”和低分体素裁剪趋势。

闭环已经打通：

`注册点云 → 独立体素化 → 生命周期属性 → 持久性代理分数 → 离线裁剪 → 图表/报告/PPT 第 3 页`

## 3. B2 系统设计

观测入口是 `map_incremental()` 已变换完成的 `feats_down_world`：它是 `camera_init` 世界坐标系下的注册、扫描下采样点云。B2 调用发生在 ikd-Tree 更新完成且 B1 核心帧计时 `t5` 结束之后。

旁路约束：

- 只读 `feats_down_world`，不重排或改写点；
- 不向 ESIKF、最近邻搜索、残差或 ikd-Tree 反馈结果；
- 每帧先在局部哈希表聚合，同一体素只增加一次 `observed_frames`；
- `total_point_hits` 累积同帧全部有限点；
- 每 60 s 传感器时间刷新帧流，并只把本周期新建体素的当前聚合状态写入检查点；
- 优雅退出时写完整最终体素 CSV 和 JSON。

## 5. 生命周期字段

最终 CSV 包含体素索引、几何中心、点均值坐标、`first_seen_time`、`last_seen_time`、`lifespan_sec`、`total_point_hits`、`observed_frames`、`active_time_bins`。时间段以正式运行第一帧时间为原点，长度 30 s。

逐帧 CSV 包含时间戳、帧号、输入点数、观测/新建/重观测体素、累计体素和观测器耗时。完整运行的 13,334 个时间戳严格递增，所有数值有限，且通过：

- `first_seen_time <= last_seen_time`；
- `observed_frames >= active_time_bins`；
- `new_voxels + reobserved_voxels = observed_voxels`；
- 累计体素数量与最终 CSV 行数一致；
- 总有限点数与所有体素点命中总和一致。

## 6. 单序列内部持久性代理分数

名义参数：`N_sat=50`、`T_sat=300 s`、时间段 30 s、权重 `(0.4, 0.3, 0.3)`。

\[
C_v=\min\left(\frac{\log(1+n_v)}{\log(1+N_{sat})},1\right),\quad
L_v=\min\left(\frac{t_{last}-t_{first}}{T_{sat}},1\right)
\]

\[
D_v=\frac{active\_time\_bins}{\max(1, lifecycle\_bins)},\quad
P_v=0.4C_v+0.3L_v+0.3D_v
\]

主展示使用 30%/70% 分位数分组，实测阈值为 `0.555847 / 0.719100`。该分组只用于解释和绘图，不改变连续分数。

| 指标 | 真实结果 |
|---|---:|
| 体素总数 | 1,267,103 |
| 分数均值 / 中位数 | 0.617843 / 0.662213 |
| P05 / P95 | 0.370517 / 0.756933 |
| 低组 | 380,131（30.0%）；占点命中 1.856% |
| 中组 | 506,841（40.0%）；占点命中 30.104% |
| 高组 | 380,131（30.0%）；占点命中 68.040% |

敏感性表测试了 `N_sat={25,50,100}`、`T_sat={150,300,600}s`、三种权重侧重和三组固定阈值。100,000 个固定随机样本上，相对名义排序的 Spearman 相关范围约为 0.743–1.000；说明排序具有一定稳定性，但对时间覆盖权重等选择仍敏感，不能把单一参数结果当作已验证真值。

| 最大/最终旋转差 | 0° / 0° |

## 11. 性能开销

| 指标 | B1 三次均值 | B2 一次全序列 | 差异/说明 |
|---|---:|---:|---|
| 核心帧均值 | 14.028 ms | 14.529 ms | +3.57%；B2 核心计时不含生命周期调用，差异含默认多线程运行变异 |
| 观测器均值 / P95 / 峰值 | — | 1.554 / 1.881 / 295.905 ms | 峰值来自 60 s 检查点批量写入 |
| 核心 + 观测器均值代理 | 14.028 ms | 16.083 ms | 相对 B1 +14.65%；为两个独立计时均值之和 |
| 进程平均 CPU | 60.045% | 63.020% | +2.975 个百分点 |
| 初始 RSS | 142.813 MiB | 154.062 MiB | +11.249 MiB |
| 峰值 RSS | 723.549 MiB | 811.938 MiB | +88.389 MiB |
| 结束 RSS | 636.189 MiB | 805.859 MiB | +169.670 MiB |

RSS 无法严谨分离：B1 是阶段 1 三次运行均值，B2 只有一次完整运行，默认多线程地图轨迹和 ikd-Tree 大小存在运行间差异。因此 RSS 差只能称为同条件进程差异，不能等同于生命周期观测器的精确内存占用。

## 14. 失败试验与局限

保留的 `b2_full_01` 使用 0.5 m 体素且每周期重写所有脏体素：到第 4,009 帧已跟踪 10,042,683 体素，检查点 1,358,467,191 bytes，峰值 RSS 2,763.527 MiB，处理降到约 4 Hz。该运行被明确停止并标记未完成，没有伪造最终 CSV/JSON。修复为 1.0 m 独立体素和“新建体素一次性检查点”，随后 `b2_full_02` 成功。

必须强调：

- 当前只有约 22 分钟单序列；
- 当前没有冻结 Ground Truth，不能评价 ATE/RPE；
- 持久性分数是单序列内部代理指标，不是长期环境持久性；
- 当前裁剪只在离线数据上模拟；
- 尚未证明在线删除不会损害定位；
- 尚未证明低持久性元素就是动态目标；
- 体素压缩比例不等同于实际 RSS 降幅；
- `feats_down_world` 是注册扫描下采样点，不等同于 ikd-Tree 全部节点；
- 分位数组是解释工具，高/中/低标签不是物理真值。
